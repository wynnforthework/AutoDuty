# 区域转换判定与录制（0.0.0.406）

## 与四条规则的对应

| 规则 | 实现与完成依据 |
| --- | --- |
| 疑似发生转换 | 加载、领地变化、异常位移、BeingMoved 或已识别弹射触发 Suspected；先停旧导航，保留步骤。无法归属的位移暂停并记录前后位置。 |
| 转换过程结束 | Travelling 阶段要求加载结束、角色可操作、BeingMoved/跳跃标记结束，并持续稳定；移动平台可按脚本关闭世界坐标静止要求。 |
| 确认抵达目的区域 | ValidatingDestination 检查地图、水平范围、高度及可选地面条件。达到连续稳定窗口后进入 DestinationConfirmed。路径查询提供额外证据。 |
| 确认步骤完成 | CompleteStep 单独验证步骤对象和索引归属、目的区域已确认、ConditionsUntil、配置的路径要求；仅在此处标记 StepCompleted，再推进。无目的区域的稳定或位移不能触发完成。 |

过程稳定与区域稳定窗口可并行采样，但只有两个窗口同时成立才确认目的地。加载或强制移动再次出现会清除稳定证据；查询期间重新移动、换地图或修改步骤会使路径结果失效。

## 运行行为

转换不再仅以固定延时作为成功依据。加载标记、地图变化和异常高速位移用于发现转换；当前步骤拥有的交互、接近触发点的移动以及脚本目的区域用于判断归属。发现转换后停止旧导航并取消旧步骤任务，避免落地后继续追逐原区域坐标。

配置了目的区域时，必须同时满足地图 ID、水平范围、高度范围、角色恢复就绪，以及默认启用的附近地面检查和连续位置稳定检查，才完成当前步骤。默认稳定窗口为 1000ms；60 秒超时只会暂停，不会当作成功。未能归属到当前步骤的异常位移会取消导航并暂停；确认回到路线入口时沿用从头执行逻辑。死亡和返回沿用专门的恢复流程。

vnavmesh 没有直接提供区域切换完成事件或区域编号。使用 `Query.Mesh.PointOnFloor` 检查落地点附近地面；目的区域稳定后，以 `Nav.Pathfind(from, to, false)` 异步查询到后续空间目标的路径，不启动移动。每次最多一个未完成请求（重置步骤也不叠加），请求间隔至少 2 秒；路径必须非空、全为有效坐标，末端水平误差不超过 2m、高差不超过 3m。换地图、重置步骤、起点移动超过 2m、目标变化或网格失效会丢弃结果。故障会被捕获并记录，框架线程不等待 Task。

默认路径是辅助证据：已有目的区域和稳定等证据仍须成立；仅为等待可选路径结果最多额外等待 3 秒，失败不会假称可达。勾选“必须确认到后续目标的有效路径”后，没有有效路径就不能完成，整体转换超时后暂停。路径成功不能替代目的区域或步骤完成条件；网格缺失也不等于仍在空中，无法覆盖的平台可显式关闭地面要求并保留区域和状态验证。

接口证据：`ECommons.IPC/ECommons.IPC/Subscribers/Vnavmesh/VnavmeshIPC.cs` 的 `Task<List<Vector3>> Pathfind(Vector3, Vector3, bool)`；本机 Hooks/dev/Dalamud.xml 的 `ConditionFlag.BeingMoved`（被强制移动）、加载和跳跃标记；沿用 Dalamud `IClientState.TerritoryType`、`IGameObject.Position`。本机 API 15。

## 脚本与编辑

MoveTo、Interactable 步骤编辑窗口新增“区域转换”配置。起点仍是步骤原坐标，触发范围可设置水平半径与高度容差（默认 10m/3m）；目的区域中心应填写转换后的落点，可落地后使用“使用当前位置”。默认目的半径 15m、高度容差 3m，可填写目的地图 ID（0 表示不限）。电梯或移动平台可按实际机制关闭位置静止要求；网格无法覆盖的平台可以关闭附近地面要求，需要实际验证后使用。

文件格式为 schema 3，仍可读 schema 1、2；共享和保存会携带 `Transition` 字段。原始脚本仍须创建副本后编辑。旧脚本不批量修改：既有 MoveTo → WaitFor IsReady → 非零位置步骤可以推断目的高度与较宽的水平范围；紧邻的 MoveTo/Boss/Interactable 空间步骤也可作为目的区域候选。无法推断的旧脚本会提示缺少目的区域并暂停，需创建副本并配置，不能仅凭加载后位置变化跳步。普通水平移动、慢速电梯等无法仅靠位移阈值可靠识别，应显式标记目的区域。

## 录制

录制会尝试识别非战斗中的加载和强制位移，等待恢复就绪、强制移动结束、位置稳定后添加转换草稿。人工标记可在机制触发前点“标记转换起点”，落地恢复操作后点“标记转换终点”。保存起点地图/位置、落地区域与有界过程采样（最多 64 条，记录经过时间、位置、地图、加载、就绪、强制移动状态；保留首条和最新采样）。采样用于复核机制，不替代运行时证据。撤回可以取消未完成的标记和自动识别。简化不会移除带转换信息的步骤。

自动识别只是候选，需检查触发点、目的范围和动作类型；跨地图录制目前仍停止并要求分别录制，手工编辑可以保存目的地图信息。未结束的人工标记不能直接保存。

## 验证与排查

离线覆盖不同楼层、不同地图相同坐标、高帧率弹射、普通行走、落地偏移、加载/角色失去就绪、地面缺失、稳定窗口重置、移动平台例外、文件往返、非法配置、编辑复制和简化保护。新增四阶段完成归属、强制移动标记、未配置目的地不跳步、异步查询不叠加、末端偏离、旧步骤/旧地图结果丢弃、限频、网格失效、异常与过程采样测试。

游戏内仍需验证：创造环境第 36/41 步弹射、交互传送、普通加载、自由落体、死亡返回、移动平台。查看 navigation-diagnostics 中的 `transferDestination`、`transferWaiting`、`transfer-timeout-evidence`；超时原因区分等待目的区域、角色加载、地面网格、位置稳定。不同电脑按实际状态等待，稳定窗口不能替代到达证据。
