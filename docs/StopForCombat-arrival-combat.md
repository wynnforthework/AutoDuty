# StopForCombat 到点战斗修复（0.0.0.399.5）

本地回归把 true 解释为途中遇战即停，导致拉怪路线在集合点前停步。现在拆分接近目标和到点执行两个阶段。

| 步骤 | 途中 | 到点完成条件 |
| --- | --- | --- |
| MoveTo | vnavmesh 移动，关闭托管输出及 BossMod 移动 | 抵达目标 |
| StopForCombat false | vnavmesh 移动，开启输出，关闭 BossMod 移动，优先瞬发 | 抵达目标，不等脱战 |
| StopForCombat true | 同 false，途中不因接战停止 | 停止 vnavmesh，交给 BossMod；观察到战斗结束且持续脱战 500ms |

零坐标直接在当前位置执行。当前步骤途中或邻近前置 MoveTo 已观察到结束的战斗无需再开一场；邻近证据不能绕过抵达目标的要求。死亡、手动跳步和路线编辑沿用证据重置。

尚未开战时等待战斗出现，超过 BossSpawnTimeoutMs 报 combat-not-started，按现有失败策略重试或暂停；正在战斗使用 BossStepTimeoutMs，避免误用较短的通用动作超时。暂停及加载不消耗动作等待时间。显式 noWait 和供 Boss 内部调用的布尔重载保留兼容行为。

Release 编译零错误，35 组离线测试通过，覆盖途中策略、未开战、战斗中、脱战稳定、新波次、已有战斗证据、零坐标和超时。尚需游戏实测，重点复测拉怪段一路抵达集合点、到点才停，以及暂停恢复与区域转换后的步骤状态。
