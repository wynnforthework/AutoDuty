## 日常使用

### 出错后恢复与热编辑

默认每步累计 3 次失败后暂停，并显示失败步骤、原因和恢复按钮。配置中可以调整次数、移动/动作/Boss 超时、提示音及失败后是否暂停。

主界面的步骤列表单击选中，双击或右键菜单从指定步骤重新执行；手动选择后暂停自动跟随滚动。构建页可在运行时插入、删除、换序或编辑步骤。编辑当前动作会取消旧动作并重新读取，插入和删除前面的动作按引用跟随当前步骤。运行时保存会写入当前路线文件，后续加载使用保存结果。

| 命令 | 用途 |
| --- | --- |
| `/ad where` | 输出当前步骤与失败信息 |
| `/ad retry` | 重新执行当前步骤 |
| `/ad step 12` | 从第 12 步执行，步号从 1 开始 |
| `/ad skipstep` | 跳过当前步骤 |
| `/ad resume` | 恢复；失败暂停时重新执行失败步骤 |

严格前置条件由步骤编辑窗口勾选。未开启时保留原来按条件跳过的语义；`ConditionsWhile` 中断会记录原因并在列表中显示。

### 录制新路线

进入副本，打开构建页的录制窗口，或运行 `/ad rec start`。开始录制会停止挂机、清空当前工作步骤，并使用独立的新文件目标。手动完成路线后停止录制，检查自动识别的 Boss、交互对象与对话选项，再保存。

| 命令 | 用途 |
| --- | --- |
| `/ad rec start` / `/ad rec stop` | 开始/停止，停止时精简移动轨迹 |
| `/ad rec add Interactable` | 添加当前目标的交互动作 |
| `/ad rec add Boss` / `/ad rec add TreasureCoffer` | 手动添加事件标记 |
| `/ad rec add Wait` / `/ad rec add MoveTo` | 添加等待或当前位置 |
| `/ad rec undo` | 撤销最后一项 |
| `/ad rec save 路线名称` | 保存为新路线，拒绝覆盖已有同名文件 |
| `/ad rec append 路线名称` | 追加到同一副本的已有路线，并显示合并后的步骤 |

录制窗口可调整采样距离、精简容差和各类事件识别开关；点击步骤可继续编辑参数。自动交互识别依据目标和对话窗口，属于候选动作；特别是 SelectString 选项需要人工补齐。战斗中的移动不作为路线采样。录制期间启动挂机会提示先停止并保存。

### 职能分流、练级与网格

路径页编辑 `Jobs` 元数据，可按 Tank、Healer、DPS 或具体职业分配路线。用户显式路径映射优先，其次匹配元数据，再使用原有 W2W 与默认路径选择逻辑。

练级筛选支持包含、仅使用包含项、排除、失败自动排除及清空自动排除。包含和排除同时设置时排除优先；等级、解锁和模式适用性仍由原有选择逻辑判断。

首次重建网格以插件会话为范围：开始挂机时该副本触发一次，同会话再次进入不再触发；插件重载后重新计数。可关闭，超时会记录警告并继续原有流程。

### 分享与导入

| 命令 | 用途 |
| --- | --- |
| `/ad path copy` | 将完整路线复制为 ADP1 分享码 |
| `/ad path copy 12-30` | 复制指定步骤区间 |
| `/ad path copy-chat` | 将有顺序编号的聊天分片复制到剪贴板 |
| `/ad path import` | 读取剪贴板中的分享码或分片 |
| `/ad path import 分享码或分片` | 导入指定内容；分片按序提交 |
| `/ad path import-file 完整文件路径` | 从 JSON 文件导入 |
| `/ad path import-url https://...` | 从 HTTPS JSON 地址导入 |

导入会先显示来源、作者、职能、步骤和敏感动作；确认后写入新文件，已有同名文件不会覆盖。默认加入不自动更新列表。ADP1 带校验和，损坏、截断、乱序或混合分片会报错。

旧 JSON 可以继续加载；新保存使用 SchemaVersion 2。旧脚本里本来无效的动作参数可能现在会触发可见失败，例如把 `WaitFor` 的参数写成 `20000`；若意图等待 20 秒，应改为 `Wait`。常见旧别名 `Ready`、`IsOcupied` 和省略 DistanceTo 的坐标等待已兼容。
