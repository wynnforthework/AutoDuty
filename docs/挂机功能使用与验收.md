## 日常使用

### 出错后恢复与热编辑

默认每步累计 3 次失败后暂停，并显示失败步骤、原因和恢复按钮。配置中可以调整次数、移动/动作/Boss 超时、提示音及失败后是否暂停。

主界面的步骤列表单击选中，双击或右键菜单从指定步骤重新执行；手动选择后暂停自动跟随滚动。构建页可在运行时插入、删除、换序或编辑步骤。编辑当前动作会取消旧动作并重新读取，插入和删除前面的动作按引用跟随当前步骤。运行时保存会写入当前路线文件，后续加载使用保存结果。

当前执行步骤始终以青色文字、选中背景及 `>` 标记显示，失败步骤优先使用红色。单击其他步骤只改变查看选择，不会取消执行步骤的高亮。列表上方的“跟随当前步骤”可恢复自动滚动；加载路线或开始一次新的导航会重置查看选择并恢复跟随。自动滚动按实际行位置定位，包含失败提示或其他额外文字时也不会按固定行高计算偏移。

| 命令 | 用途 |
| --- | --- |
| `/ad where` | 输出当前步骤与失败信息 |
| `/ad retry` | 重新执行当前步骤 |
| `/ad step 12` | 从第 12 步执行，步号从 1 开始 |
| `/ad skipstep` | 跳过当前步骤 |
| `/ad resume` | 恢复；失败暂停时重新执行失败步骤 |

严格前置条件由步骤编辑窗口勾选。未开启时保留原来按条件跳过的语义；`ConditionsWhile` 中断会记录原因并在列表中显示。

### 录制新路线

进入副本，打开构建页的录制窗口，或运行 `/ad rec start`。开始录制会停止挂机、清空当前工作步骤，并使用独立的新文件目标。手动完成路线后停止录制，检查自动识别的 Boss、交互对象与对话选项，再保存。

| 命令 | 用途 |
| --- | --- |
| `/ad rec start` / `/ad rec stop` | 开始/停止，停止时精简移动轨迹 |
| `/ad rec add Interactable` | 添加当前目标的交互动作 |
| `/ad rec add Boss` / `/ad rec add TreasureCoffer` | 手动添加事件标记 |
| `/ad rec add Wait` / `/ad rec add MoveTo` | 添加等待或当前位置 |
| `/ad rec undo` | 撤销最后一项 |
| `/ad rec save 路线名称` | 保存为新路线，拒绝覆盖已有同名文件 |
| `/ad rec append 路线名称` | 追加到同一副本的已有路线，并显示合并后的步骤 |

录制窗口可调整采样距离、精简容差和各类事件识别开关；点击步骤可继续编辑参数。自动交互识别依据目标和对话窗口，属于候选动作；特别是 SelectString 选项需要人工补齐。战斗中的移动不作为路线采样。录制期间启动挂机会提示先停止并保存。

### 职能分流、练级与网格

路径页编辑 `Jobs` 元数据，可按 Tank、Healer、DPS 或具体职业分配路线。用户显式路径映射优先，其次匹配元数据，再使用原有 W2W 与默认路径选择逻辑。

练级编排在独立的“练级编排”页中进行。主页自动练级区域直接列出已编排副本、进入等级、自动匹配脚本、完成度与状态，并标记下一副本。需要修改时再打开编排页。录制与导入入口统一保留在构建页。

目录来自游戏的 `ContentFinderCondition` 数据，包含没有本地脚本的新副本；内置 `levelingList` 及跳过动画条件下的补充名单只定义默认方案。游戏数据更新并重启插件后，新副本会进入目录；新副本不会在没有脚本时自动运行。

每行显示进入等级、使用/跳过、自动匹配脚本、平均完成度、无干预通关比例、当前等级经验效率及不可用原因。勾选“使用”可把默认名单以外的副本加入方案；勾选“跳过”排除；两项都取消恢复默认。仅使用包含项、失败自动排除等旧设置保持兼容。

不再填写职业等级区间或优先级。按游戏规定的进入等级选择已编排且可运行的最高等级副本。例如启用 20、23、24 级副本时，20–22 级使用 20 级本，23 级切换到 23 级本，24 级切换到 24 级本。缺脚本、未解锁或装备/信赖条件不满足时回退。旧配置中的手动区间、优先级和效率推荐字段保留读取兼容，但不参与选本，避免旧设置暗中改变新规则。

副本编排在当前配置中由所有职业共用，切换职业或职能不需要重新编排。脚本列只读，展示已有职业/职能规则自动匹配的结果；特定职业的脚本分配统一在“脚本路径”页管理。缺脚本时到构建页录制或导入。切换职业后脚本与成绩重新计算。修改编排在下一次选择副本时生效，运行中的路线不被替换。

经验效率保留为比较数据，不自动改变按进入等级递进的顺序。这里使用副本内经验/尝试耗时，不含排队；完整练级效率仍以统计页包含排队和暂停的会话经验/小时为准。

首次重建网格以插件会话为范围：开始挂机时该副本触发一次，同会话再次进入不再触发；插件重载后重新计数。可关闭，超时会记录警告并继续原有流程。

### 分享与导入

| 命令 | 用途 |
| --- | --- |
| `/ad path copy` | 将完整路线复制为 ADP1 分享码 |
| `/ad path copy 12-30` | 复制指定步骤区间 |
| `/ad path copy-chat` | 将有顺序编号的聊天分片复制到剪贴板 |
| `/ad path import` | 读取剪贴板中的分享码或分片 |
| `/ad path import 分享码或分片` | 导入指定内容；分片按序提交 |
| `/ad path import-file 完整文件路径` | 从 JSON 文件导入 |
| `/ad path import-url https://...` | 从 HTTPS JSON 地址导入 |

导入会先显示来源、作者、职能、步骤和敏感动作；确认后写入新文件，已有同名文件不会覆盖。默认加入不自动更新列表。ADP1 带校验和，损坏、截断、乱序或混合分片会报错。

旧 JSON 可以继续加载；新保存使用 SchemaVersion 2。旧脚本里本来无效的动作参数可能现在会触发可见失败，例如把 `WaitFor` 的参数写成 `20000`；若意图等待 20 秒，应改为 `Wait`。常见旧别名 `Ready`、`IsOcupied` 和省略 DistanceTo 的坐标等待已兼容。

### 完成度与挂机数据概览

打开统计页，可查看本次挂机时长、副本完成/尝试次数、无干预完成次数、经验、每小时经验和提升等级。旧统计保留在下方折叠区。运行中的统计不允许清空。

完成度使用第一次问题发生前连续处理的步骤数除以总步骤数。只有从首步开始、处理完全部适用步骤并收到副本完成事件，且没有失败或手动干预，才记为 100%。例如 100 步脚本在第 41 步失败，完成度保持 40%；随后修复通关也不会抹除本次问题。脚本本身按职业、同步模式等设计的可选跳过计为已处理，并单独记录数量。步骤全部处理但未确认通关时，最高显示 99.9%。

自动记录失败、卡住恢复、死亡、暂停、跳步、热编辑及绑定移动键输入。聊天或 ImGui 文本输入时不将按键误计为移动。手动战斗、鼠标移动和手动交互不能全部自动识别，发生此类干预时请点击“标记手动战斗 / 交互干预”；目前统计不能作为完全无人干预的独立证明。

脚本对比按副本、脚本内容哈希、具体职业、模式、队伍人数和多开状态分组。修改动作后会产生新版本的成绩组。失败和停止也是样本，保留首次卡点；不会仅统计成功通关的运行。会话每小时经验包含排队与暂停，脚本分组每小时经验使用副本内尝试耗时，两种口径分别显示。

使用“复制统计报告”分享当前筛选范围内已结束的尝试；接收方点击“从剪贴板合并报告”。报告不含路线文件，移除角色 ID，保留匿名贡献者编号与运行编号，相同运行不会重复导入。共享数据是贡献者提供的测量记录。取消“仅本次挂机”可对比多人的历史样本；其他语言目前使用英文后备文案，简体中文有完整文案。

“当前配置的 16–100 级覆盖情况”检查 16–99 级对应的可运行副本与所选路线，目标为 100 级。它使用当前职业、解锁、装备和练级筛选，匹配脚本版本、模式、多开及当前队伍人数。可调整最低样本数；只有匹配样本全部无干预完成才标为候选。候选并不保证未来运行成功，也不代表已经完成全程实测。后续优化应先补齐缺失样本、修正高频卡点，再比较会话每小时经验；信赖 NPC 等级、未来装备及角色解锁变化仍需实际练级验收。

## 职能脚本与录制范围

相邻战斗步骤衔接：`StopForCombat=True` 是切换“遇战停步”模式，不是必须触发一场新战斗的检查点。新增执行期证据记录：当前步骤或紧邻的前一个MoveTo步骤在该坐标6米内确实观察到战斗，随后脱战，且玩家仍在6米内时，可直接执行该模式切换，无需继续精确寻路到原点。它仍执行原动作，完成后再推进，不把“附近没怪”当作完成依据。没有这份证据时，沿用正常移动和动作流程；StopForCombat这种模式切换的坐标到达容差设为1.5米，避免因过严的0.25米判定在目标附近反复寻路。

证据按具体步骤对象保存，只覆盖StopForCombat=True及紧邻的MoveTo，不用于Boss、交互、等待开战或其他步骤。远处战斗、死亡、跳步、编辑路线和停止执行不能复用这份证据。再次接战时清除“已脱战”标志。记录的是接战与脱战，不据此宣称所有敌人都已消灭。

主页新增当前执行状态、距目标坐标的距离和当前队列任务名，区分“仍在走点”“正在执行动作”和“等待当前战斗结束”。升级后请从副本开始验证，因为不会推测升级前发生的战斗。本次已通过截图坐标场景、缺少证据、远处战斗、Boss隔离、新波次、死亡/手动重置等离线回归；尚未进行游戏内验收。

步骤删除与暂停恢复修复：编辑窗口的“删除”立即按原步骤对象执行，不再等待切换到构建页；主页步骤右键菜单也提供删除。编辑期间前面插入或重排了步骤，仍定位到原步骤；原步骤已删除时不误删其他步骤。删除会按现有保存逻辑写入当前文件。

移动中暂停后恢复，会重新寻路到当前步骤，不会跳过步骤；动作中恢复保留任务队列，不重新调用同一动作。重复暂停不覆盖暂停前的状态，暂停期间不执行自动步骤检查。任务队列暂停开关只在值改变时切换，避免重复注册框架回调。

本次离线验证包括步骤对象定位、删除后的文件持久化，以及移动、动作、战斗等待和循环的恢复策略。游戏内的删除按钮及Pause / Resume操作尚待实测。

### 同一副本保留多份路线

“构建”页始终显示当前编辑的完整文件路径。填写“新路径名称”后点击“另存为测试路径”，会把当前内存中的步骤和原元数据保存到独立文件，并切换为编辑这份副本；原文件和其他职能分配不变。同名文件会拒绝覆盖，不再通过实时修改路径名称输入框来切换保存目标。

“本副本的全部路径文件”以及职能管理面板会列出每个文件，可分别编辑、复制和切换测试草稿状态。新建、复制、另存和新录制默认都是测试草稿，不会自动替换职能分配，也不参与自动匹配。旧文件默认保留原来的自动匹配资格。

测试方法：停止挂机，进入目标副本，在主页的路径下拉框手动选择草稿，再执行测试。单文件副本也提供下拉框。选择草稿只供当前手动测试，不修改已保存的职业分配；重新进本恢复原自动方案。验证后在文件列表点击“验证后允许自动匹配”，再从坦克、治疗或DPS下拉框明确指定文件。启用自动匹配可能影响原有元数据匹配与默认回退，所以先检查分配再开启自动练级。

例如可同时保留“坦克稳定版”“坦克拉怪测试A”“坦克验证B”“治疗路线”和“DPS路线”。后续步骤编辑自动保存到当前明确选中的文件，不会合并这些路线。

新回归用例验证了同副本多副本文件隔离、原文件不变、同名拒绝覆盖、草稿自动匹配排除、元数据和共享状态保留。尚未进行游戏内界面与通关验收。

步骤保存修复：确认步骤修改、新增、删除、复制、重排或严格条件切换后，会自动写入当前脚本文件，并保护该文件免于路径更新覆盖。“构建”页显示最近保存时间、完整文件路径或失败原因；失败时聊天栏也会报错，可以点击“保存路径”重试。删除最后一步会保存空脚本，空脚本不参与自动练级。清空整条路线仍须显式点击“保存路径”。

保存采用临时文件替换，保留磁盘中的作者、职能等元数据，不再重置为第一个路径。重新加载路线时直接从磁盘读取步骤。录制过程、切换编辑文件和接收主机路径不触发自动保存，录制仍须使用录制窗口的保存按钮。

回归测试已验证修改写入后重新读取、元数据与变更记录保留、无效写入不破坏原文件、最后一步删除，以及录制/加载与自动保存的隔离；游戏内重新进本仍需实测确认。

在“练级编排”中，每个副本的脚本列可以打开“管理坦克 / 治疗 / DPS脚本”。各职能分别选择现有文件，切换职业无需重新编排。界面同时显示实际匹配的文件；若以前按单职业分配过不同文件，会显示多个文件。

- “移除职能指定”删除该职能的覆盖分配，恢复原有自动匹配，不删除磁盘文件。
- “新建脚本”建立该职能的独立草稿；“复制为独立脚本”复制当前唯一匹配的文件，保留原职能分配。验证并启用草稿后，再明确指定职能。多个文件分别匹配不同职业时，可在下面的文件列表逐个操作。
- “编辑步骤”将文件加载到构建页；副本外也能增删改步骤并保存，保留原元数据。共用文件的修改影响所有使用它的职业；需要独立步骤时先复制。
- 新建、复制和切换编辑须先停止挂机与录制；空脚本不参与自动练级。尚未安装脚本的副本也有新建入口。
- “脚本路径”页也提供同一个职能管理面板，并保留原有细分职业设置。

录制器目前不能自动识别构建器的全部动作。自动检测仅包括移动采样、附近Boss和宝箱、选中的EventObj交互物、出现的Talk / SelectYesno / SelectString对话框。交互物被选中不等于交互成功；Boss和宝箱出现不等于玩家已经完成对应动作。对话使用默认或占位参数，不能识别玩家实际选项，必须校对。

录制窗口的“手动补录动作（全部动作）”直接使用构建器的动作目录与参数编辑器，可补录技能 / 道具、跳跃、聊天指令、等待条件、专属机制等。它不会自动推断条件和分支。录制后仍须检查步骤、对话参数与条件，再实测完整通关。
